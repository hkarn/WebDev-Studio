# WebDev Studio

How the owner's hobby web apps are built: shared standards for a Next.js + PostgreSQL stack, a
Docker-first dev container, CI, dependencies, security and coding-agent setup, so a new app or a
new agent session doesn't need the setup explained again.

- Agents start at [AGENTS.md](AGENTS.md).
- [standards/](standards/README.md): the standards, and which apps follow them.
- [apps/INDEX.md](apps/INDEX.md): the apps and their repositories.
- [history/](history/README.md): where the standards came from (cold).

The apps' code, decisions and state live in their own repositories. The standards are written to
be reusable: copy what fits your own project.
